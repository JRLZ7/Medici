# Contributing

Use the setup in README.md. Keep changes small and verify with `npm run check`, `npm run build`, and `npm test`.

- Preserve original media and original-video timestamps.
- Keep observations, interpretations, and uncertainty distinct.
- Do not seed findings into real experiments or enable inference implicitly.
- Preserve procedure versions and review history; avoid relinking old observations by step number.
- Keep private data and credentials out of Git and logs.
- Test meaningful validation, persistence, and security behavior when changing those boundaries.

No model calls, paid services, cloud deployment, or training-data collection are part of the initial workflow.
